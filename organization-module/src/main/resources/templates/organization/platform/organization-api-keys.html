Signing Keys

This Organization's own active signing key (ADR-0010 §5.2), PEM-encoded. Paste it into a backend or edge environment for networkless JWT verification, without fetching the JWKS URL at runtime. Rotate it on the Signing Keys page.

If you hardcode this value, rotating the signing key will break verification of newly issued tokens immediately — there is no grace period for a static copy the way there is for the JWKS URL above. Prefer fetching the JWKS URL at runtime unless you have a specific reason not to.
